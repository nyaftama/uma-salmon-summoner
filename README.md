# ウマ娘 なんでもSHAKEROCKメーカー (UMAMUSUME SALMON SUMMONER)

任意の画像にゲーム「ウマ娘 プリティーダービー」のおさかな（「Thisマグロ」や「シャケ」）を持たせることができるファンメイドのWeb画像ジェネレーターです。  
立体的なおさかなの角度・位置・サイズ調整、手元になじませるマスク合成（削り・復元）、元ネタ風のド派手なポップロゴ、PV再現風の字幕作成、背景のトリミングや位置調整などの機能を搭載しています。

- **Webアプリ**: [https://nyaftama.github.io/uma-salmon-summoner/](https://nyaftama.github.io/uma-salmon-summoner/)
- **作者**: [@nyaftama](https://nyaftama.github.io/)

---

## 主な機能

1. **背景画像の調整（「背景」タブ）**
   - 画像の読み込み（ファイル選択、ドラッグ＆ドロップ、クリップボードからの貼り付け）
   - iPhone等で撮影された各種画像の自動読み込み対応
   - アスペクト比の選択（元画像、1:1、16:9、4:3、9:16、3:4）
   - キャンバス上での自由な背景位置調整（パン移動）

2. **「SHAKEROCK!」風 ポップロゴ（「ロゴ」タブ）**
   - 好きな文字（1行目・2行目）の入力
   - キャンバス上での直感的なドラッグ移動

3. **PV風 字幕機能（「字幕」タブ）**
   - 白文字＋黒細枠スタイルの明朝体字幕表示
   - 1行・2行のテキスト入力と自由なドラッグ移動・サイズ調整

4. **おさかなの調整（「おさかな」タブ）**
   - 「Thisマグロ」と「シャケ」の切替
   - ドラッグ操作による位置調整、平面回転、3D立体回転
   - サイズ・立体的な厚みの調整、光源の色（シアン・レッド・イエローなど12色のプリセット ＆ 自由なカスタムカラー）の選択

5. **手元になじませるマスク機能（「マスク」タブ）**
   - おさかなの上から手や指の領域をなぞって消すことで、自然に持っているような合成表現が可能
   - 直感的なブラシサイズ調整とリアルタイムプレビュー

6. **画像の生成 ＆ シェア**
   - 作成した画像の保存・ダウンロード
   - クリップボードへの画像コピー
   - X（旧Twitter）へのシェア（`#なんでもSHAKEROCKメーカー`）

## 使い方

1. **背景画像を準備する**
   - 画像をアップロードまたは貼り付け、「背景」タブでアスペクト比や表示位置を整えます。

2. **おさかな・ロゴ・字幕を調整する**
   - 「おさかな」タブでおさかなの種類や角度、光源の色を調整します。
   - 「ロゴ」や「字幕」タブでお好みのテキストを入力し、キャンバス上で位置や大きさを調整します。
   - 右上の「有効」スイッチでロゴや字幕のON/OFFを切り替えることもできます。

3. **手元をなじませる**
   - 「マスク」タブでおさかなを掴んでいる指や手の部分をなぞって削り、合成をなじませます。

4. **生成・保存**
   - 「画像を生成・保存」ボタンを押し、完成した画像をダウンロードまたはXでシェアします。
