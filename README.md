# ウマ娘 なんでもサーモンサモナー (UMAMUSUME SALMON SUMMONER)

任意の画像にゲーム「ウマ娘 プリティーダービー」の3Dおさかな（「Thisマグロ」や「シャケ」）を持たせることができるファンメイドのWeb画像ジェネレーターです。  
Three.js による立体的な膨らみを持つ 3D/2.5Dモデルの回転・拡大・移動操作、手元・切り抜きブラシ（削り・復元）機能、元ネタ風のド派手なカスタムポップロゴ（「SHAKEROCK!」など自由編集可能）の作成・配置機能、および背景構図パン移動・アスペクト比トリミング機能を備えています。

- **Webアプリ**: [https://nyaftama.github.io/uma-salmon-summoner/](https://nyaftama.github.io/uma-salmon-summoner/)
- **作者**: [@nyaftama](https://nyaftama.github.io/)

---

## 主な機能

1. **多彩な画像入力 ＆ 背景構図調整（「背景」タブ）**
   - ファイル選択 / ドラッグ＆ドロップによるアップロード
   - クリップボードからの直接貼り付け（Ctrl+V / Cmd+V）
   - iPhone等で撮影された HEIC/HEIFフォーマット画像の自動変換対応
   - アスペクト比トリミング切り替え（元画像、1:1、16:9、4:3、9:16、3:4）
   - 「背景」タブでの背景画像自由ドラッグ移動（パン調整） ＆ 3x3構図ガイド表示

2. **「SHAKEROCK!」風 カスタムロゴ作成 ＆ 配置**
   - 任意テキスト（1行目・2行目）のカスタム入力
   - キャンバス上での直感的なドラッグ移動 ＆ 回転ガイドリングによる回転操作

3. **3D/2.5D おさかなの自由な操作 ＆ 回転ガイド円**
   - Three.js を使用した立体的な3Dおさかなオブジェクト（「Thisマグロ」/「シャケ」切り替え対応）
   - 表側・裏側テクスチャおよび輪郭自動ディスプレイスメントマップ生成による「胴体の厚み（立体膨らみ）」表現
   - キャンバス上でのドラッグ移動・3D回転ドラッグ操作
   - 拡大縮小スライダー、立体膨らみスライダー、ライティングカラー（光源の色）変更

4. **マスクによる合成機能**
   - おさかなの上に被せる手や指をブラシで透過描画することで、自然に持っている手元表現を実現
   - ブラシサイズは画像解像度に依存しない「0.1%〜15.0%」刻み指定 ＆ スライダー調整時のリアルタイム中央プレビュー
   - マスクの追加時にふわっと香る「削り節」エフェクト

5. **保存 & X（Twitter）連携シェア**
   - 高解像度Canvas合成
   - PNG画像のダウンロード
   - クリップボードへの画像コピー
   - X（Twitter）へのダイレクトシェアリンク生成

## 使い方

1. **背景画像を読み込む ＆ 構図を整える**
   - ファイルをドラッグ＆ドロップするか、クリップボードから貼り付けます。
   - 「背景」タブでアスペクト比（1:1, 16:9等）を選択し、キャンバス上をドラッグして背景位置を調整します。

2. **「ロゴ編集」でオリジナルロゴを作成・配置する**
   - 「ロゴ編集」タブを開き、テキスト（1行目・2行目）を入力。
   - キャンバス上のドラッグ移動および回転ガイドリング（ハンドルノブ）で好みの位置に配置します。

3. **おさかなの種類・位置・角度・サイズ・光の色を調整する**
   - 「おさかな移動」で「Thisマグロ」または「シャケ」を選択。
   - キャンバス上のドラッグ操作（移動・2D回転・3D回転）やコントロールパネルで調整します。

4. **手元・前面を削る（持たせる）**
   - タブを「マスク」に切り替え、おさかなを掴んでいる手や指の領域をブラシで削ります。

5. **生成・保存**
   - 「画像を生成・保存」ボタンをタップして完成画像をプレビューし、ダウンロードやX（Twitter）シェアを行います。
