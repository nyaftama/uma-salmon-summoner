# ウマ娘 なんでもサーモンサモナー (UMAMUSUME SALMON SUMMONER)

任意の画像にゲーム「ウマ娘 プリティーダービー」の3Dおさかな（「Thisマグロ」や「シャケ」）を持たせることができるファンメイドのWeb画像ジェネレーターです。  
Three.js による立体的な膨らみを持つ 3D/2.5Dモデルの回転・拡大・移動操作、手に持たせるための「手元・切り抜きブラシ（削り・復元）」およびライティングカラー調整機能を備えています。

- **Webアプリ**: [https://nyaftama.github.io/uma-salmon-summoner/](https://nyaftama.github.io/uma-salmon-summoner/)
- **作者**: [@nyaftama](https://nyaftama.github.io/)

---

## 主な機能

1. **多彩な画像入力対応**
   - ファイル選択 / ドラッグ＆ドロップによるアップロード
   - クリップボードからの直接貼り付け（Ctrl+V / Cmd+V）
   - iPhone等で撮影された HEIC/HEIFフォーマット画像の自動変換対応

2. **3D/2.5D おさかなの自由な操作**
   - Three.js を使用した立体的な3Dおさかなオブジェクト（「Thisマグロ」/「シャケ」切り替え対応）
   - 表側・裏側テクスチャおよび輪郭自動ディスプレイスメントマップ生成による「胴体の厚み（立体膨らみ）」表現
   - キャンバス上でのドラッグ移動・3D回転ドラッグ操作（タッチ操作対応）
   - 2D回転（Z軸）、拡大縮小スライダー、立体膨らみスライダー
   - ライティングカラー（光源の色）の自由変更

3. **直感的な削りブラシ ＆ 手元・前面合成機能**
   - おさかなの上に被せる手や指を「削る」ブラシで透過描画することで、自然に持っている手元表現を実現
   - ブラシサイズは画像解像度に依存しない「0.1%〜15.0%」刻み指定 ＆ スライダー調整時のリアルタイム中央プレビュー
   - 「削る」操作時にふわっと香る「削り節」エフェクト
   - 「元に戻す」ブラシ / 削りの1つ戻す (Undo) / 削りを全消去 (リセット)

4. **保存 & X（Twitter）連携シェア**
   - 高解像度Canvas合成
   - PNG画像のダウンロード
   - クリップボードへの画像コピー
   - X（Twitter）へのダイレクトシェアリンク生成

## 使い方

1. **背景画像を読み込む**
   - ファイルをドラッグ＆ドロップするか、クリップボードから貼り付けます。読み込み完了時に自動でエディターへスクロールします。

2. **おさかなの種類・位置・角度・サイズ・光の色を調整する**
   - 「Thisマグロ」または「シャケ」を選択し、キャンバス上のドラッグ操作（移動/3D回転）やコントロールパネルでサイズ・2D回転・胴体の厚み・光源の色を設定します。

3. **手元・前面を削る（持たせる）**
   - タブを「切り抜き」に切り替え、おさかなを掴んでいる手や指の領域を「削る」ブラシでなぞります。削った部分が手前に突き抜けて自然な手元表現になります。

4. **生成・保存**
   - 「画像を生成・保存」ボタンをタップして完成画像をプレビューし、ダウンロードやX（Twitter）シェアを行います。
